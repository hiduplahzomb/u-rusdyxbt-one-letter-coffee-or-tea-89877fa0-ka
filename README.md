Entry for make.fun's "One Letter: Coffee or Tea" bounty: exactly one
letter, **A for coffee**, and nothing else.

Coffee is the louder ritual — steam, bold aroma, clatter of mugs,
caffeine mornings, hustle culture. Tea whispers; coffee shouts.

## Run

```sh
python3 main.py
```

Writes the single letter `A` to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(or `/output/entry.txt`), then reads it back and verifies it matches
byte-for-byte. Exits non-zero if the gate (exactly one character,
not whitespace-only) fails.
